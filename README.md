# LifeLog AI

> 你的智能生活记录助手

基于 Vue 3 的个人生活记录应用，集成 AI 分析功能。

## ✨ 功能特性

### 📊 记账本
- 收入/支出记录管理
- 月度统计图表（折线图、饼图）
- AI 消费分析
- 批量删除
- 本地存储

### 📝 心情日记
- 每日心情记录
- 5 种心情标签
- AI 情绪分析

### 📌 备忘录
- 待办事项管理
- 优先级设置
- 今日提醒

### 🤖 AI 助手
- 流式对话
- 多会话管理
- 上下文记忆

### 🌤️ 天气助手
- 实时天气
- 自动定位
- AI 天气分析

### 💾 数据管理
- 导出/导入备份
- 一键清除

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| Vue 3 | 前端框架 |
| TypeScript | 类型系统 |
| Pinia | 状态管理 |
| Vue Router | 路由管理 |
| Element Plus | UI 组件库 |
| ECharts | 数据可视化 |
| DeepSeek API | AI 对话 |
